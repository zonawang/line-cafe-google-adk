# Day 05｜Runner＋events：看懂一次工具呼叫

Phase 2 · 約 45～60 分鐘 · [總路線](../ROADMAP.md) · [今日文章](../articles/day-05.md)

## 先懂這兩件相連的事（10～15 分鐘）

**Runner 與 event：流程是怎麼被執行的？**

Runner 驅動 agent 或 workflow；執行途中可能產生工具呼叫、工具回傳與回覆等 event。最終答案只是整段執行的一部分。

**第一次整理：五分鐘講清楚 agent 與 tool**

複習日用來確認自己能說明概念。能修改範例與預測結果，比記住所有類別名稱更重要。

## 用咖啡 Bot 想一遍

最終答案看起來正確，工具卻沒有被呼叫，這份結果是否符合你原本的設計？

先自己回答兩三句，再動手驗證；答不出來可回看[概念速查](../docs/concepts.md)，不用讀完整份官方文件。

## 動手做（25～30 分鐘）

1. 在開發介面或 CLI 跑一次工具查詢與一次缺資料問題。
2. 依序記錄使用者輸入、工具呼叫、工具回傳與最終答案；圈出第一個需要檢查的步驟。
3. 用一分鐘錄音說明 model、agent、tool、runner；把一個卡點帶到後續，不增加功能。
