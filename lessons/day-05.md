# Day 05｜用任務與限制寫 instruction

Phase 1 · 約 30～45 分鐘 · [總路線](../ROADMAP.md) · [今天的文章](../articles/day-05.md)

## 今天只懂這件事

Instruction 應說清楚任務、資料來源與不知道時的行為。只寫「你是專業助理」無法交代哪些資料能用，也無法保證數字正確。

## 動手做（15～20 分鐘）

1. 把 starter 的 instruction 改成「用兩句繁中說明，不猜個人紀錄」。
2. 問「我這個月去了幾間店？」與「你能怎麼幫我？」。
3. 各保留一則回覆，標出模型是否承認沒有資料。

## 做到這裡就好

- [ ] 資料不足時會說明需要紀錄，而非編造造訪次數。
- [ ] 留下一項證據：程式差異、輸出、流程圖或口頭說明錄音。
- [ ] 花十分鐘完成[今日短文](../articles/day-05.md)，更新[學習紀錄](../learning-log.md)。
