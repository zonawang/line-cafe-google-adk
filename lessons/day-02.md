# Day 02｜選定護照主線，跑出第一個 agent

Phase 1 · 約 45～60 分鐘 · [總路線](../ROADMAP.md) · [今日文章](../articles/day-02.md)

## 先懂這兩件相連的事（10～15 分鐘）

**從舊 repo 選一條最小改造路線**

遷移適合從可觀察、可比較的小流程開始。咖啡護照本來就把資料讀取、統計與摘要拆開，能用同一份資料比較原程式與 ADK。

**建立第一個 LlmAgent**

LlmAgent 把模型、任務說明與可用工具放在一起。最小 agent 可以先只有一項任務；本日只請它解釋咖啡護照，不接資料庫。

## 用咖啡 Bot 想一遍

這個 agent 回答了「你去了 5 次」時，問題出在模型不夠強，還是任務與資料邊界沒寫清楚？

先自己回答兩三句，再動手驗證；答不出來可回看[概念速查](../docs/concepts.md)，不用讀完整份官方文件。

## 動手做（25～30 分鐘）

1. 讀 repo 盤點的 passport handler，找出讀取、統計、摘要與呈現四個呼叫。
2. 照 starter README 檢查環境、安裝套件並設定自己的 key，執行 `npm run agent`。
3. 問「咖啡護照能幫我什麼？」與「我這個月去了幾間店？」，保留回覆並標出目前沒有資料來源。

## 做到這裡就好

- [ ] 一份明確的小範圍：本月護照＋零筆＋模型失敗；一個可執行的最小 agent。
- [ ] 用自己的話回答上方情境題，指出觀念與實作的關係。
- [ ] 留一張圖、一段輸出或一個程式差異，標記資料來源與未完成部分。

## 寫今天的一篇文章（10～15 分鐘）

打開[今日草稿](../articles/day-02.md)，用 300～500 字串起兩個觀念，加入一個真實結果與一個原本的誤解。最後在[學習紀錄](../learning-log.md)寫下一句理解。今天只完成圖解也可以如實記錄。
