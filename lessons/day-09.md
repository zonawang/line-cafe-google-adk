# Day 09｜Runner 與 event：流程是怎麼被執行的？

Phase 2 · 約 30～45 分鐘 · [總路線](../ROADMAP.md) · [今天的文章](../articles/day-09.md)

## 今天只懂這件事

Runner 驅動 agent 或 workflow；執行途中可能產生工具呼叫、工具回傳與回覆等 event。最終答案只是整段執行的一部分。

## 動手做（15～20 分鐘）

1. 在 ADK 開發介面或 CLI 檢視一次昨日工具呼叫。
2. 依序記下使用者訊息、工具名稱、工具結果與最終回覆。
3. 在筆記畫出這四步，不必手寫自訂 Runner。

## 做到這裡就好

- [ ] 能用一筆真實執行紀錄說明 agent 有沒有查工具。
- [ ] 留下一項證據：程式差異、輸出、流程圖或口頭說明錄音。
- [ ] 花十分鐘完成[今日短文](../articles/day-09.md)，更新[學習紀錄](../learning-log.md)。
