# Day 25｜用五個案例檢查結果與路徑

Phase 5 · 約 30～45 分鐘 · [總路線](../ROADMAP.md) · [今天的文章](../articles/day-25.md)

## 今天只懂這件事

Agent 的驗證要同時看回答內容與執行過程。統計適合確定性斷言，生成文案則檢查有沒有改數字、編造或超出範圍。

## 動手做（15～20 分鐘）

1. 跑 `docs/demo.md` 五個案例：正常、零筆、模型失敗、跨使用者、模糊期間。
2. 對每個案例勾結果與路徑，留下失敗原因。
3. 不要從五個案例推論整體準確率；這份是專案驗收表，不是 ADK 官方 evalset。

## 做到這裡就好

- [ ] 五個案例有實際紀錄；今天可修缺陷與補進度。
- [ ] 留下一項證據：程式差異、輸出、流程圖或口頭說明錄音。
- [ ] 花十分鐘完成[今日短文](../articles/day-25.md)，更新[學習紀錄](../learning-log.md)。
