## 常見問題的短答方向

- **一定要多 agent 嗎？** 先依任務決定。這個例子一個摘要 agent 加一般函式即可。
- **有 graph 就不會幻覺嗎？** Graph 規定流程，內容仍需要資料約束與驗證。
- **原本的函式做不到嗎？** 做得到；比較的是控制、觀察與擴充所帶來的效益與成本。
- **ADK 會幫我記住所有咖啡紀錄嗎？** 永久紀錄仍由應用資料庫管理，context 與 memory 需要另外設計。
- **一定要部署 GCP 才能學嗎？** 可先從本機與 fixture 學流程；實際模型與服務需設定自己的驗證方式。
