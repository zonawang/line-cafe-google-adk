# Agent 怎麼從「會說明」變成「會用資料回答」？

> Day 03 · 第一人稱學習紀錄草稿 · [今日實作](../lessons/day-03.md)
> 實作尚待完成；本文以計畫語氣撰寫，做完後再補入真實結果。

先讓 agent 跑起來之後，我接著想處理一個很實際的問題：它要去哪裡拿到咖啡紀錄？

如果只告訴它「你是咖啡助理」，它還是不會知道我去了幾間店。今天想把兩件事接在一起：寫清楚任務，以及提供真正可用的程式能力。

我會先在 instruction 裡限定它根據資料回答，再用 FunctionTool 包一個小函式，固定提供三次造訪、兩家店的示範統計。這些都是假資料，目的是觀察工具結果怎麼進入回答。

工具本身很像一個附有使用說明的程式入口：名稱告訴 agent 這是什麼，用途描述說明何時該呼叫，execute 裡才放真正的工作。

這樣一來，回答裡的數字就有了可以回頭檢查的來源。今天要確認的，是 agent 有沒有呼叫工具，以及最後說出的次數是否忠於工具結果。
