# 讓 agent 能做事的第一步：把函式變成 tool

> Day 06 · 概念短文草稿 · [今日實作](../lessons/day-06.md)
> 狀態：待實作與個人編輯。下方概念文字可改寫使用；成果欄位請做完再填。

函式本來就能計算與查詢。包成工具後，agent 可以根據用途描述選擇呼叫它，再使用回傳資料回答。這個連結讓語言理解與既有程式服務接在一起，也保留了程式端驗證資料的機會。
