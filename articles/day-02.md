# 先挑一條小流程，再建立第一個 Google ADK agent

> Day 02 · 第一人稱學習紀錄草稿 · [今日實作](../lessons/day-02.md)
> 實作尚待完成；本文以計畫語氣撰寫，做完後再補入真實結果。

上一篇，我先把 Google ADK 放回原本的咖啡 Bot 裡，整理 LINE、資料庫、模型與流程各自負責什麼。

接下來想往前走一小步：先讓第一個 agent 跑起來。

我挑的是自己熟悉的咖啡護照。原本的程式已經會讀足跡、算統計，再請 Gemini 寫回顧；資料與文案分得很清楚，很適合拿來慢慢接入 ADK。

今天的起點先放得很小：建立一個 LlmAgent，告訴它用繁體中文簡短介紹咖啡護照。名稱讓我知道它是哪個角色，model 指定使用的模型，instruction 則交代它的工作。

這時還沒有接個人紀錄。如果我問「這個月去了幾間店」，它應該說明目前沒有資料。先確認這個邊界，後面才知道加入工具到底改變了什麼。

這篇實作時，我想留下兩則回覆：一則介紹用途，一則面對缺資料的問題。第一個 agent 能清楚完成這個小工作，就可以繼續下一步了。
