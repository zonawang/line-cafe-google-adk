# 給 agent 一個角色之後，還要告訴它哪些事不能猜

> Day 05 · 概念短文草稿 · [今日實作](../lessons/day-05.md)
> 狀態：待實作與個人編輯。下方概念文字可改寫使用；成果欄位請做完再填。

一個實用的 instruction 同時包含任務與邊界。咖啡護照的數字應來自程式統計，模型負責整理語句。當紀錄尚未提供，合理的回答是說明缺少什麼，而不是用自然的語氣填滿未知。

## 補上今天自己的紀錄

- 今天的小改動或圖解：〔待填〕
- 我實際看到的結果與證據：〔待填：輸出、截圖或 commit〕
- 一個原本的誤解，以及現在的理解：〔待填〕

可以用「原本遇到的問題 → 今天懂的一件事 → 一個真實結果 → 明天的小問題」寫成 200～400 字。若今天只完成圖解，就清楚寫圖解，不寫成已上線功能。
